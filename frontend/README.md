# Linkpulse frontend

React + Vite + TypeScript + Tailwind dashboard for the Linkpulse API. See the root README for the full project.

```bash
npm install
npm run dev        # http://localhost:5173 (expects the API on http://localhost:8000)
npm run typecheck
npm run lint
npm run build
```

Environment (build time): `VITE_API_BASE_URL` (default `http://localhost:8000`), `VITE_SHOW_DEMO_LOGIN` (`false` hides the demo button).
